# マイコン部 紹介サイト

GitHub Pages で公開しているクラブ紹介サイトです。

## 文章を直したいとき

1. `index.md` を開いて、鉛筆マーク（Edit）を押す
2. 文章を書き換える
3. 「Commit changes」を押す → 数分でサイトに反映されます

## 書き方のルール

- `## 見出し {#英単語}` で新しいセクションになります（ページ内リンクも自動で増えます）
- `- ` で始まる行は箇条書き、`**文字**` は太字です
- `〇` になっているところは仮の内容なので、正しい情報に書き換えてください
- ページ上部のお知らせ・数字・ボタンは、`index.md` の一番上（`---` で囲まれた部分）で変えられます

## デザインを変えたいとき

- 色やフォント：`assets/css/style.css` の一番上
- ページの骨組み：`_layouts/default.html`

## 注意

- このリポジトリは公開されています。個人名・連絡先・顔写真などの個人情報は載せないでください。
