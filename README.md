# OMPUマイコン部 ホームページ

https://ompu-maikon.github.io

GitHub Pages（Jekyll）で公開しています。ファイルを編集してCommitすると、数分でサイトに反映されます。

## ファイルの場所

| 変えたいもの | ファイル |
| --- | --- |
| トップページ（見出し、写真、ターミナルの文字） | `index.md` |
| マイコン部について | `about.md` |
| 活動内容 | `activities.md` |
| 入部案内（流れ・先輩の声・質問・問い合わせ） | `join.md` |
| お知らせの記事 | `_posts` フォルダ |
| メニュー | `_config.yml` の `nav:` |
| 色・フォント | `assets/css/style.css` の一番上 |

## トップの写真を差し替える

1. 写真を `assets/images` フォルダにアップロードします（例：`assets/images/top.jpg`）
2. `index.md` の `hero_image:` の行を `hero_image: /assets/images/top.jpg` に書き換えます

横長で、2000px程度の大きさの写真がおすすめです。顔が写っていない写真を使ってください。

## お知らせを追加する

`_posts` フォルダに、`年-月-日-英単語.md` という名前でファイルを作ります。

例：`_posts/2027-04-10-report.md`

```
---
title: 4月の活動報告
category: 活動報告
---

ここに本文を書きます。
```

「お知らせ」ページに、新しい順で自動的に表示されます。

## 本文の書き方（Markdown）

- `## 見出し` … 新しいセクションになり、自動で番号が付きます
- `- **タイトル** 説明` … すべての項目を太字で始めると、カード表示になります
- `1. **タイトル** 説明` … 番号付きで書くと、STEP表示になります
- `> 文章` … 枠付きの引用（先輩の声など）になります
- `| 項目 | 内容 |` … 表になります
- `![説明](画像のURL)` … 画像を入れられます。画像は `assets/images` フォルダに置きます

## ページを増やす

1. `about.md` をコピーして、新しい名前（例：`works.md`）で保存します
2. 上の `---` の中の `title`・`label`・`nav`・`permalink` を書き換えます（例：`nav: works`、`permalink: /works/`）
3. `_config.yml` の `nav:` に同じ `id` で1つ追加すると、メニューとトップページに表示されます
